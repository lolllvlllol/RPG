# RPG Life System

Консольное приложение на Go, которое превращает развитие реальных навыков в RPG-систему.

Пользователь заполняет ежедневный отчёт, получает XP за свои действия, повышает уровни навыков и общий уровень персонажа, а также выполняет ежедневные миссии.

## Возможности

- Система XP и уровней
- 5 навыков:
  - Strength
  - Sleep
  - Programming
  - Nutrition
  - Discipline
- Расчёт прогресса каждого навыка
- Общий уровень персонажа
- Текстовые progress bar
- Ежедневный отчёт
- Ежедневные миссии
- Случайный выбор 5 миссий на день
- Начисление XP и Mission Points за выполненные миссии
- Защита от повторной сдачи миссий в течение одного дня
- Автоматическое создание новых миссий при наступлении нового дня
- Сохранение прогресса игрока в JSON
- Сохранение состояния ежедневных миссий в JSON

## Ежедневные миссии

Каждый день игрок получает 5 случайных миссий.

За выполнение миссий начисляются:
- XP соответствующего навыка
- Mission Points

Для успешного выполнения дневного набора необходимо набрать не менее 100 Mission Points.

После сдачи результат сохраняется, поэтому повторно получить XP за те же миссии в этот день нельзя.

## Запуск

Требуется установленный Go.

```bash
go run .
```

Проверка проекта:

```bash
go fmt ./...
go vet ./...
go build ./...
```

## Структура проекта

```text
internal/
├── calculate/   # расчёт XP и обработка миссий
├── iointerface/ # ввод и вывод данных
├── model/       # структуры данных
├── update/      # обновление уровней и состояния
└── workjson/    # работа с JSON

rpgMain.go       # основная логика приложения
missions.json    # база ежедневных миссий
```
