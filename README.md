# RPG Life System

Консольная RPG-система для отслеживания развития себя, как персонажа в RPG мире.
Позволяет ощутить себя в игре и контролировать свои параметры, а так же отслеживать их прогресс на дистанции.

## Возможности
- XP система
- Навыки
- Уровни
- Прогресс персонажа
- Система сна
- Система дисциплины
- Сохранение прогресса в JSON

## Запуск

```bash
go run .
```
